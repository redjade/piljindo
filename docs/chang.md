# 장쉰의 3장과 함께 읽기

장쉰 《한자 서예의 미》(김윤진 옮김, 글항아리, 2024)의 3장은 감지하는 능력에서 출발해 점부터 일곱 획을 살핀다. 공개 목차에서는 점이 먼저이고 力·辶 같은 글자 예가 보인다. 이 순서가 장쉰이 참고한 판본에서 왔는지, 설명을 위해 다시 배열한 것인지는 본문과 사용 판본을 확인해야 한다. [이 자료의 붓 연습](practice.md)은 명대 《진체비서》본의 획표 순서를 따른다. 힘력 力, 주살 익 弋, 쉬엄쉬엄 갈 착 辶은 획을 찾아볼 현대 글자 예다. 명대 판면에는 그 자리에 단독 획표가 있다. 특히 乚처럼 보이는 표지는 《제후》의 戈와 함께 읽을 때 갈고리의 들리는 끝이 또렷해진다. 乀의 움직임은 辶 전체를 한 획으로 보는 것과 다르다. [저본 13번](../assets/plates/najda-13.jpg) · [저본 14번](../assets/plates/najda-14.jpg) · [《제후》 H03](postface.md#h03--송익이-획을-바꾸다)

책을 다시 펼칠 때에는 한 절을 읽고 해당 획을 한 번 써 본다. 설명을 먼저 읽었을 때와 먹이 마른 뒤 다시 읽었을 때 어떤 낱말이 새로 눈에 들어오는지 살핀다.
