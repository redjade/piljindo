# 두 글의 글자 풀이

원문에서 이어지는 글자를 어구별로 묶어 그 자리에서의 뜻을 풀이했다. 흔히 쓰는 독음과 글자 뜻은 [한자표](characters.md)에 있다. 한자표와 다른 독음이나 고유명사의 읽기가 필요한 곳은 이 표에 한 글자씩 대응시켜 적었다. 일곱 획의 머리에 붙은 표시는 도형 이름으로 풀이한다. 번역과 판독에 여지가 있는 곳은 두 글의 주석을 함께 본다.
